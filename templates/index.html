Expand & Train Your Deepfake Model

To make your deepfake detector highly robust, you need to train it on a larger diversity of images. We have configured the 140k Real & Fake Faces dataset to fit your existing pipeline perfectly.

Step 1: Download the Dataset

We created a custom python downloader script to make this easy. In your local workspace terminal, execute:

python download_dataset.py

This script will:

  1. Help you authenticate with the Kaggle API.
  2. Download the 1.2 GB dataset automatically.
  3. Extract and restructure folders to match your notebook's folder structure (e.g. Dataset/Train/Fake).

Step 2: Train on Google Colab

Since training 140,000 images on a local CPU takes a long time, we recommend training in Google Colab using a free GPU:

  1. Compress the newly downloaded Dataset/ folder into a zip file named Dataset.zip.
  2. Upload Dataset.zip to your main Google Drive directory.
  3. Open your notebook in Google Colab and run it. The first few cells will automatically mount your Google Drive and extract Dataset.zip to Colab's workspace.

Step 3: Export Model to Frontend

Once your model finishes training in Colab, append this code cell to the end of your notebook and run it to save your trained weights:

# Save the model
model.save("deepfake_model.h5")
from google.colab import files
files.download("deepfake_model.h5")

Place the downloaded deepfake_model.h5 file directly inside this project's root folder and restart the server. The status indicator in the top right will change to LIVE MODE, and the web app will use your custom AI model to run real-time inference!
